Política de privacidade do Ofertei

Atualizada em 30 de outubro de 2026.

O Ofertei é uma extensão do Chrome que gera o seu link de afiliado e o texto do post de oferta. Ele foi feito para funcionar inteiro no seu navegador: não temos servidor que receba os seus dados.

O que o Ofertei guarda

  • Suas configurações (lojas escolhidas, etiqueta, tag, códigos e dados de API de afiliado). Ficam no armazenamento do próprio Chrome. Se você usa a sincronização do Chrome com a sua conta Google, o Chrome copia essas configurações para os seus outros computadores.
  • Seus últimos posts (até 30) e a contagem de posts do dia, só neste computador.

O que o Ofertei acessa

  • A página do produto aberta, quando você clica na extensão: para ler nome, preço, foto e cupom.
  • Os sites das lojas e dos programas de afiliados (Mercado Livre, Shopee, Amazon, Magalu, AliExpress, Natura e Netshoes/Rakuten): para gerar o link de afiliado com a sua própria conta. Para isso a extensão usa o login que você já fez nesses sites, no seu navegador. Seus cookies e senhas nunca saem do seu computador e nunca são enviados para nós.
  • Encurtadores de link (is.gd, ulvis.net ou, se você configurar, TinyURL): quando o seu link de afiliado fica muito comprido, ele é enviado a um desses serviços públicos para virar um link curto. Só o link vai; nenhum dado seu.
  • O WhatsApp Web, só quando você pede para enviar o post: para colar a foto e o texto na conversa que você escolher. A extensão não lê suas conversas.

O que o Ofertei não faz

  • Não vende, não aluga e não compartilha dados com ninguém.
  • Não troca o seu link de afiliado pelo de outra pessoa.
  • Não envia mensagens sozinho: todo envio acontece quando você clica.
  • Não usa os dados para publicidade nem para avaliar crédito.

Como apagar tudo

Remova a extensão em chrome://extensions. As configurações e o histórico guardados pelo Ofertei são apagados junto.
